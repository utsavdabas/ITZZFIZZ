# ORBIT Motion Landing Page

A recreation of the uploaded video's visual idea using a different moving object.

## Stack
- Next.js
- React
- JavaScript
- Tailwind CSS
- GSAP
- HTML/JSX + CSS

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Main files

- `app/page.jsx` — React page + GSAP animation + SVG spacecraft
- `app/globals.css` — custom CSS + Tailwind directives
- `tailwind.config.js` — Tailwind configuration
- `package.json` — dependencies/scripts

## Replace the object

Inside `app/page.jsx`, replace the `<SpaceShip />` SVG with your own SVG or product markup.

Good alternatives to a car:
- spacecraft
- sneaker
- smartphone
- robot
- drone
- perfume bottle
- motorcycle helmet
- gaming controller
